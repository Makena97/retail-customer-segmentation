# Ethical AI Principles

The BrightCart Customer Segmentation Analytics project will follow five
principles:

1. Fairness
2. Transparency
3. Accountability
4. Privacy
5. Human oversight

Customer segmentation and predictive analytics will be used as decision-support
tools rather than autonomous decision-makers.

The project will avoid using protected characteristics for segmentation and will
evaluate potential bias and limitations where appropriate data is available.
